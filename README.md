# WeThinkCode_ AI Curriculum Exercises

This repository contains my completed exercises, activities, reflections
and supporting evidence from the WeThinkCode_ AI Curriculum.

## About

The curriculum focused on using Generative AI to support software
development and learning. The exercises covered areas such as:

- Using AI to improve programming knowledge
- Learning a new programming language with AI
- Learning frameworks, libraries and APIs
- Understanding FastAPI code patterns
- Using AI responsibly during software development

## My Approach

I used AI as a learning support tool rather than relying on it to
complete everything for me. I focused on understanding the explanations,
reviewing suggestions and reflecting on what I learned from each activity.

## Repository Structure

- `01-deepening-current-language` – Activities focused on improving
  understanding of programming concepts and code quality.
- `02-learning-new-language` – Activities relating to learning a new
  programming language with AI.
- `03-fastapi` – Exercises relating to learning FastAPI.
- `04-ai-principles` – Reflections on responsible and effective use of AI.
- `evidence` – Supporting evidence and final reflections.
