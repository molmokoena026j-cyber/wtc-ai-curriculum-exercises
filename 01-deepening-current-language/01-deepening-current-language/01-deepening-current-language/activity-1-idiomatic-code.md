# Activity 1: Idiomatic Code Transformation

## Objective

The purpose of this activity was to improve my understanding of writing code in a way that is natural and appropriate for the programming language I am using.

## What I learned

### 1. Working code is not always idiomatic code

I learned that code can work correctly but still be written in a way that is not considered the best approach for a particular programming language. Idiomatic code makes use of the language's own features and conventions instead of treating it like another language.

### 2. Readability is important

I learned that writing code is not only about getting the correct result. The code should also be easy for another developer to understand. Using clear names, appropriate structures and simpler approaches can make code easier to read and maintain.

### 3. AI suggestions need to be understood before being used

One of the most important things I learned is that I should not accept an AI suggestion simply because it looks better or shorter. I need to understand why the change is being suggested and whether it actually makes sense for my code.

## Reflection

This activity helped me realise that improving as a developer is not only about learning how to make code work. It is also about learning how to write code properly and understanding the conventions of the language. Using AI helped me identify areas I might not have noticed on my own, but I still needed to understand and evaluate the suggestions before applying them.
