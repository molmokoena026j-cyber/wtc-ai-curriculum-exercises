
# Activity 3: Understanding a Language Feature

## Objective

The purpose of this activity was to learn more about a programming language feature that I was not very familiar with and understand how it can be used in practice.

## What I learned

### 1. Programming languages have features that are designed for specific problems

I learned that it is useful to understand not only the basic syntax of a language but also the features that can make certain tasks easier. Different features exist for different purposes, and knowing when to use them is part of becoming more comfortable with a programming language.

### 2. Understanding the purpose is more important than memorising syntax

I learned that I do not need to memorise every feature immediately. What is more important is understanding what the feature does, why it exists and what type of problem it can solve. Once I understand the purpose, it becomes easier to use the feature correctly.

### 3. Practical examples make new concepts easier to understand

I found that seeing a feature used in a small, realistic example makes it easier to understand than only reading a definition. Implementing a small example also helped me identify questions and mistakes that I would not necessarily notice from an explanation alone.

## Reflection

This activity showed me that there is more to learning a programming language than knowing basic syntax. There are features and patterns that become useful as problems become more complex. AI was useful for explaining unfamiliar concepts and giving examples, but I still needed to work through the examples and understand what was happening instead of simply copying the code.
